# Sakura Petals

A cherry blossom theme for Claude Code in the desktop and mobile apps. Pink petals of every size drift down behind your session, swaying and fluttering as they fall, and settle into a soft drift that heaps up in the bottom corners the longer the session runs. It fills in about 36 minutes, then stays.

- Light and dark mode: a pale blush or a deep plum background, with matching pink app colors.
- The drift stays low in the middle, under the message box, and keeps out from behind your text.
- Respects your system's reduced-motion setting.

## Commands

- `/sakura-sweep`: sweep the pile away and start a fresh one.

## Install

At the prompt of a terminal session:

```
/plugin install sakura-petals --marketplace mightymauls/sakura-petals
```

Answer `y` to add the marketplace, then pick a scope (user scope loads it in every session).

From a shell:

```bash
claude plugin install sakura-petals --marketplace mightymauls/sakura-petals
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `mightymauls/sakura-petals`, then Add plugin.

The theme draws in the desktop and mobile apps; the terminal and editors show no backdrop.
